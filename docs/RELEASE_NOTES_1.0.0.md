# UIGrade AI 1.0.0 — Release notes dự thảo

Đây là bản Android demo đầu tiên hoàn thiện proof-of-flow cho Sinh viên, Giảng
viên và Admin.

## Nổi bật

- Jetpack Compose/Material 3, theme xanh và mascot mèo.
- Navigation phân quyền ba vai trò.
- Lớp học, mã tham gia, assignment, draft/submission và lịch sử.
- Rubric/rule/metric, chấm deterministic, lecturer review và công bố điểm.
- Dashboard, thông báo, hồ sơ và Admin audit.
- Unit test, Compose smoke test và GitHub Actions.

## Giới hạn

Dữ liệu nằm trong RAM, session reset khi app dừng. Chưa có backend, Room, token,
RLS hoặc AI provider thật. APK chỉ dành cho demo, không dùng dữ liệu sinh viên thật.
